홈페이지의 무료상담·빠른설치·3초견적·하단 상담신청·B2B·파트너점 문의가 아래 구글 시트에 한 줄씩 쌓이고,
shin299fa@naver.com 으로 알림 메일이 갑니다.

- 시트: https://docs.google.com/spreadsheets/d/1MMq5ivibbzLrtAr3OVGz02oNz5HlIFHcv0ohR1iRTSw/edit (dlb776@gmail.com 드라이브)

## 연결 구조

홈페이지 신청 창 (`tools/consult.js`) → POST → Apps Script 웹 앱 (`tools/consult_apps_script.gs`) → 시트 1행 추가 + 메일

| 시트 열 | 보내는 값 (POST 이름) | 어디서 오나 |
|---|---|---|
| 접수일시 | (스크립트가 기록) | 접수 시각 |
| 구분 | type | 무료상담 신청 / 3초 견적 / 빠른설치 신청 / 하단 상담 신청 / 사업자/단체 견적 문의 / 파트너점 모집 문의 |
| 성명 | name | 신청 창 성명 |
| 연락처 | tel | 신청 창 연락처 |
| 상품 | product_nm | 상품 페이지에서 자동 (약정 포함) |
| 상품번호 | product_no | 상품 페이지에서 자동 |
| 설치지역 | area | 신청 창 (선택) |
| 문의내용 | memo | 신청 창 / B2B 문의내용 |
| 견적 | estimate | 3초견적: 약정·색상·월 렌탈료 |
| 회사명 | company | B2B 문의 |
| 이메일 | email | B2B 문의 |
| 페이지 | page | 신청한 페이지 주소 |

## 설정 (처음 한 번, 약 5분) — dlb776@gmail.com 으로 로그인한 상태에서

1. 위 시트를 엽니다.
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 편집기 내용을 모두 지우고 `tools/consult_apps_script.gs` 내용을 전부 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 > 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 허용 ("확인되지 않은 앱" 경고가 나오면 고급 > 이동)
5. 화면에 나온 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사해서 작업자에게 전달합니다.

작업자는 이 URL을 `tools/consult.js` 의 `ENDPOINT` 에 넣고 다시 빌드·배포한 뒤 시험 신청으로 시트·메일을 확인합니다.
URL이 들어가기 전까지는 신청 버튼을 누르면 "070-8652-7471 로 전화 주세요" 안내가 뜹니다.
