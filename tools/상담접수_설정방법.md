# 상담 신청 받기 설정 (구글 시트 + 메일 알림)

홈페이지의 무료상담·빠른설치·3초견적·하단 상담신청·B2B·파트너점 문의가 구글 시트에 쌓이고,
shin299fa@naver.com 으로 알림 메일이 갑니다. 처음 한 번만 설정하면 됩니다(약 5분).

1. https://sheets.google.com 에서 **빈 스프레드시트**를 새로 만들고 이름을 `홈페이지 상담신청`으로 바꿉니다.
2. 메뉴 **확장 프로그램 > Apps Script** 를 엽니다.
3. 편집기에 있는 내용을 모두 지우고, `tools/consult_apps_script.gs` 파일 내용을 전부 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 > 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 구글 계정 권한 허용(“안전하지 않음” 경고가 나오면 고급 > 이동)
5. 화면에 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해서 작업자에게 전달합니다.

작업자는 이 URL을 `tools/consult.js` 의 `ENDPOINT` 에 넣고 다시 빌드·배포합니다.
URL이 들어가기 전까지는 신청 버튼을 누르면 “070-8652-7471 로 전화 주세요” 안내가 뜹니다.
